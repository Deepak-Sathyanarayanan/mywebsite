Overview

This project is an end-to-end AI platform for processing trade finance documents such as commercial invoices, bills of lading, letters of credit, and packing lists. It is designed to extract structured information from complex financial documents and make the document collection searchable and queryable.

The platform combines OCR, layout-aware document classification, entity extraction, vector search, and RAG-style question answering to support faster review of trade finance document packages.

Features

  • Classifies trade finance documents into supported document types.
  • Extracts key entities such as invoice numbers, supplier names, buyers, dates, totals, ports, and shipment details.
  • Indexes document text into a vector database for semantic search.
  • Supports retrieval-augmented question answering over document collections.
  • Provides API endpoints through FastAPI and interactive Swagger UI.
  • Includes synthetic trade finance documents for demonstration and testing.

Architecture

Trade Finance Documents → OCR → Layout-Aware Classification → Entity Extraction → ChromaDB Vector Index → Semantic Search / RAG → Answers + Evidence

System Capabilities

Document Classification

The system uses document text and layout signals to identify the type of trade finance document being processed. This creates the foundation for downstream extraction and search.

Entity Extraction

The platform extracts structured entities from unstructured documents, helping convert trade finance paperwork into machine-readable data that can support review, analysis, and automation.

Semantic Search

Extracted document text is embedded and stored in a vector database, allowing users to search by meaning rather than exact keywords.

RAG-Based Question Answering

The platform retrieves relevant document context and uses it to answer questions about the trade finance document collection with supporting evidence.

How to Run

# Clone repository
git clone https://github.com/Deepak-Sathyanarayanan/trade-finance-intelligence.git
cd trade-finance-intelligence

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run API
uvicorn app.main:app --reload

Open the FastAPI documentation at: http://127.0.0.1:8000/docs
