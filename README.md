# mywebsite

Personal portfolio website for showcasing my work in Data Science, Machine Learning, NLP, Document AI, and AI-powered analytics.

## Overview

This repository contains my personal portfolio website, built to highlight my background, technical skills, resume, and selected projects. It serves as a central place to present my work in data science and related areas, including applied machine learning, natural language processing, document intelligence, retrieval-augmented generation, analytics, and end-to-end project delivery.

## Features

- Personal portfolio homepage
- About page with professional background
- Contact page
- Project gallery
- Individual project pages with visuals, demos, screenshots, and summaries
- Resume access
- GitHub Pages deployment

## Project Areas

The website currently showcases projects in areas such as:

- Retrieval-Augmented Generation (RAG)
- Trade Finance Document AI
- OCR and layout-aware document understanding
- Speech Recognition
- Twitter Sentiment Analysis
- Fraud Detection

## Featured Projects

- **AI Research Assistant (RAG over arXiv Papers)** — Retrieval-augmented generation system for querying arXiv papers with grounded responses.
- **Trade Finance Document AI Platform** — Document intelligence platform for processing invoices, bills of lading, letters of credit, and packing lists using OCR, LayoutLMv3, entity extraction, ChromaDB semantic search, and RAG-style retrieval.
- **TensorFlow Speech Recognition** — Speech-command classification pipeline using MFCC features, TensorFlow, and FastAPI.
- **Twitter Sentiment Analysis** — Large-scale NLP sentiment classification workflow using text preprocessing, embeddings, and neural networks.
- **Health Insurance Fraud Detection** — Fraud detection workflow using multi-source healthcare claim data, dimensionality reduction, and classification.
